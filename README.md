This repo is a single-line submission for [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) on make.fun.

The joke skips every obvious toaster pun. A slice gets wedged, and instead
of asking for help with the jam, the toaster treats it as a haunting and
sends for the clergy — then warns its owner to keep the slot shut. Execute
`main.ts` and the line lands in `/output/entry.txt` exactly as written:
65 characters, nothing after the final full stop, not even a newline.

> ERROR: Bread stuck. I have called a priest. Do not open the slot.

```sh
node main.ts
```
